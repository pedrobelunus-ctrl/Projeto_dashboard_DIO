Dashboard para atividade do bootcamp 
Uma dashboard simples sobre imóveis criado através de uma planilha no excel, não foi preciso usar arquivo markdown pois a planilha estava com dados limpos 
Por está iniciando e ser primeiro contato com ferramentas as tiver algumas dificuldades para subir no começo para o repositório, mas acabou dando certo.
O intuito da dashboard é mostrar detalhes e informações importantes sobre cada empreendimento.
